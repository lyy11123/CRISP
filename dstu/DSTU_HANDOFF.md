### 9.1 2A（r = 1）

余量统一参数化（Kao & Garcia-Molina，TPDS 1997，投稿前核对原文）：`S = d_req − r − p̂_M − p̂_F`，`D_M(α) = r + p̂_M + αS`。所有方法用同一个外部 `d_req`；FFN 阶段截止时间都是 `d_req`。

| 层 | 方法 | 跑法 |
|---|---|---|
| 不用预测 | UD（`D_M = d_req`）；窗口对半（评估里的“均分”）；固定比例 0.3 | 后处理 |
| 粗预测 | 聚合代价 + ED | 先只比键 |
| 过时预测 | 故障前画像 + ED；故障前画像 + EQF（与当前 CPCM 的同 α 配对） | 后处理 |
| 当前预测 | CPCM + ED（α = 1）；+ EQF（α = p̂_M / (p̂_M + p̂_F)）；+ EQS（α = 0.5） | 后处理 |
| 参照 | 单流后端画像 + ED | 只报枚举 |

- 评估里的“按 T 比例”就是 EQF（无故障 29,709），不要重复算；此时 `D_M = k_req · p̂_M`，与 `k_x = k_req`、X 为同长 MHA 且同释放的 `d_x` 会撞平。平局规则写明（−ln），平局格单独计数。
- **聚合代价**用论文批评的那种量：当前平台上最忙资源的累计占用（最忙链路、最忙张量或向量单元的累计时间取最大），单位是时间。字节数加总没有时间单位，不能和 `d_req` 比，只作次要枚举。
- 只有键不同的格子才涉及仿真。聚合代价如与 CPCM 顺序不同，用已有的固定排名后处理给出 L̂；相同就如实报告相同。
- 每行只由两个二元先后决定，以上方法都映射到已有固定排名，不增加进程，仍约 65 个。
- 报：各方法相对 CPCM + ED 的顺序不同比例；**顺序不同的行单独汇总**；相邻键的间隔、估计误差与排序翻转率（`|Dᵢ − Dⱼ| > |eᵢ| + |eⱼ|` 时排序不变）；旧画像按硬件分开。

**选切方法：**

| 方法 | 分数 |
|---|---|
| 随机对照 | 同尺寸候选里固定种子抽 3 次（即原“按大小”） |
| φ_wait | i* 自身活动的等待区间 [can, s] 内，其他流在同一链路上的服务重叠，按原始消息汇总 |
| φ_res | φ_wait 中只算可由块间仲裁缓解的部分：阻塞者优先级低于 e，且 `s_b < can_e < f_b`，取 `min(f_b, s_e) − can_e` |
| Greedy | 见下 |

- i* = 最大归一化迟约流，不是全局最后完成的流。

- 池 B 保留时，非 D2D 消息的动作分两档（→256 KB、→64 KB），按实际成本记账。

## 10. 阶段 2C：全链路 256 KB 上的复测（用户 2026-11-06 放行）

“全链路 256 KB”指所有大于 256 KB 的消息都切成 256 KB，a1、a2 都如此。

**先查（只读，不跑）：** 后端和 CPCM 里每多一块的开销是怎么建模的（启动时间、逐跳、仲裁），写进汇总；不要改模型。

**10.1 2A 重跑：** 网格、方法、指标同第 9.1 节，只把切块换成全链路 256 KB。T_M、T_F、T̂、聚合代价、外部 d 都在这个切块上重新取。报告同 2A 的主表，并与只切 D2D 的同行配对。

**10.2 CPCM 试算选序（CP_SIM，新方法）：** 对每行枚举 M、F 相对 X 的 4 种排名，用 CPCM 前向算出各排名的 C，代入该行的 d 和 T 得预测 L̂，选最小者；预测相同时取 CP_ED 的排名。用到的排名都要有后端结果（补跑没出现过的）。只切 D2D 和全链路 256 KB 两种切块都做。对比 CP_ED、UD、聚合代价 + ED，以及事后最好（oracle，同一行 4 种排名里后端 L̂ 最小者）。报：L̂ 中位、最差；相对 oracle 的遗憾；选中排名与 oracle 一致的比例；顺序不同的行单独汇总。注明选序要跑几次 CPCM 和耗时。

**10.3 2B 换基线：** a2 9 个配置，k = 1.5，dᵢ、Tᵢ 沿用第 9.2 节（统一 256 KB D2D 的值，便于和阶段 2 直接比）。

- A 组（同预算，起点 D2D 256 KB，540 档）：补一个静态选切，与已有的全链路 256 KB、φ_res B256、随机 B256 配对。
- B 组（起点全链路 256 KB，再加 540、1,620 块）：动作是 D2D 或非 D2D 消息从 256 KB 切到 64 KB，每条 54 块。分数在全链路 256 KB 的排程上重算。方法：φ_res、随机（固定种子 3 次）、静态选切。参照：全链路 256 KB、全链路 64 KB。
- **静态选切（不用时序）：** 分数 = 该消息与 i* 流共用的链路数 × 消息字节数，只看路由和字节，不看时间。i* 取相应起点上 CPCM 算出的最差流（如不再是 MHA 要报告）。同分用固定种子打破。
- 报：L̂、C_MHA、C_FFN、完成时间、新增块、`extra_occupancy`；φ_res 对静态、随机、全链路 256 KB 的配对差；静态与 φ_res 所选方案的重合度。

**10.4 阶段 1 复测：** 设定 1，全部配置，策略 P1、FCFS、P4、BestFixed、P7、C4、C-S，全链路 256 KB，种子沿用阶段 1。Tᵢ、T̂ᵢ、dᵢ 都在这个切块上重新取，同时报绝对完成时间，因为 Tᵢ 变了 L̂ 不能直接和只切 D2D 比。

- 报：各策略 L̂ 中位、最差；相对 FCFS、P1 的改善（用 E4a 里“好 20–66%”的同一公式，并列出只切 D2D 的对应值）；C4 − C-S 配对，格式同阶段 1；C-S 保留比例；反例子集。a1、a2 分开报。
- 设定 2、3 不跑。结果要不要往后推，由用户看完决定。

不做：Greedy、r = 8、A3h、自适应 α、改模型或核实硬件可行性。
