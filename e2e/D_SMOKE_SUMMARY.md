# D：S-B 冒烟与自检汇总

2026-11-11，场景改定之后（`E2E_HANDOFF.md` 第 6 节末）。只报数字。

- **代码：** `e2e\d_joint.py` 的 `sim_sb`、`sb_smoke`；诊断用 `e2e\d\out\sb_diag.py`。
- **输出：** `e2e\d\out\sb_smoke\`。
- **口径：** 本机，tag 哈希，线程数 1，最多 8 个并行。
- **状态：** 用 D0 的导出（C 的状态，T̂ 已逐一核对）。

**共用资源（无故障与 PF4，事实）：**

- KV 与 P 共用 co2co 97–101 条、ch2ch 11–12 条。
- pf_ffn（没有 KV）与 D 共用 0 条。
