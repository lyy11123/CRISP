本机后处理使用保存的快照和评估记录，没有新增搜索或后端仿真。批量墙钟与进程时间描述本次运行，优化器的独立串行计时按既定 J 阶段安排。

健康结果的 23 项检查全部通过：3080 个保存状态、30800 条后端种子记录、56 个工作量记录和 1176 行静态资源负载已解析。八种算子的有效 TensorCore 工作量在七个主配置间一致。故障后处理读取 10090 条后端样本，1009 个状态均值与结果文件吻合；512 条停止记录、609 次联合实验和 203 个相位分组复算通过。6869 个结果文件与先前下载的最终记录逐字节相同，6400 处保存文件引用全部可在本机找到。

## 结果解释检查

| 检查项 | 本次处理 |
|---|---|
| 合并统计是否掩盖分组差异 | 先按硬件、规模、故障、相位分别统计，保留 DSTU 的改善与回退数量。 |
| 算子结果能说明什么 | 单组算子是直接仿真；单层、固定 KV 请求由公式组装；E 的 44 层结果另列。 |
| 候选选择带来的差异 | 保存全部十四候选，同时报告后端选优、候选中位数与 CPCM 选优。 |
| 条件筛选是否改变比较对象 | 物理故障按计划从正式映射选取，同一配置的比较臂使用同一故障。 |
| 各类情况的数量是否清楚 | 分别列明 128 个故障单元、各修复种子、609 次联合与每相位三个后端种子。 |
| 最好候选是否被当成典型情况 | 最好候选与候选分布分开，不将其推广为其他搜索预算或未知种子的保证。 |
| 失败是否造成结果缺失 | 全部计划作业已补齐；两次失败尝试和成功重试分别记录，原失败历史保留。 |
| 是否只呈现有利结果 | 提供完整表格，正文包含 LN/投影回退、EIR 七个变差单元和 DSTU 的 P 延迟代价。 |
| 分析选择是否在看结果后改变 | 实验设置沿用已批准的 FG_PLAN，本轮新增的是只读汇总与解释。 |
| 工作量相关性是否被当成独立原因 | 快照资源工作量用于解释；模块增量来自匹配实验臂，逐链路排队时序没有另行推测。 |
| 改善方向是否支持所写结论 | 分别比较 A3h、EIR、切块和 C4 的增量，整体 CRISP 对 B-R0 的改善不全部归给 DSTU。 |

结果采用描述性统计。搜索种子、同候选的后端种子和修复种子分别记账；重复评估数量不作为独立硬件样本数量。CPCM 的 2% 停止条件与真实后端恢复程度分别报告。迟约为负表示提前完成余量，负值变大与实际超期分开统计。
